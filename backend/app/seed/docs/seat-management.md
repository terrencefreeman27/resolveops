# Seat Management

## How seats work

Each active user occupies one seat regardless of role. An account cannot have more active users
than purchased seats. Deactivated users do not occupy seats.

## Adding seats

Admins add seats in **Settings → Billing → Seats**. Added seats are available immediately and are
billed as a prorated seat add-on for the rest of the current billing period (see "Proration and
Plan Changes").

## Removing seats

Seat reductions take effect at the next renewal. No credit is issued for the current period.

## Seat limit reached

When all seats are in use, inviting a new user fails with the message "No seats available". The
Admin must add seats or deactivate an existing user first.
